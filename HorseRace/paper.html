Simulated Horse Racing: Probabilities of Sums of Non-Standard Dice

Background

When I was I kid I saw a game at a local festival that interested me. It was a horse racing game where each kid would pick a horse and place it on the track. They would take turns rolling a die and moving their horse forward that many squares. The first person to cross the finish line won tickets that could be traded in for prizes. Later on I thought, what if that was a casino/gambling game that people could bet on similar to how people can already bet on horse racing. In order to properly bet on the race you would need to set the payoff odds, and in order to do that you would need to calculate each horses probability of winning the race. Obviously with standard dice, each horse would have an equal probability of winning. I thought this was boring and much like real race horses, wanted the probabilities to be varied which would allow people to bet on favorites for a low payout, or go with the longshot and possibly hit it big. To accomplish the difference I imagined each horse would have some non-standard die where the face were not the standard 1 through 6. Problem Statement

There are p players playing a game. Players roll a die in rounds, adding the result of their roll to their own personal total. The first player to surpass some threshold, T, wins. What is the probability of each player winning the game? Players roll simultaneously in rounds and in the event of a tie, players share the win. I imagined other tie breaking criteria when imagining the game, but for simplifying the calculations determined players will equally share the win.

Calculations

Dice can be represented as a polynomial, `f(x)= a_0x^0 + a_1x^1 + ... + a_nx^n`, with each term representing a value on the die. The exponent is the value of the side, and the coefficient is the frequency of that value. a standard die would therefore be `s(x) = 1x^1 + 1x^2 + 1x^3 + 1x^4 + 1x^5 + 1x^6`.

You can subsquently find the sum of n dice rolls by multiplying the polynomials together. `f(x)^n` For example, the sum of 2 dice rolls would be `(1x^1 + 1x^2 + 1x^3 + 1x^4 + 1x^5 + 1x^6)^2`, which if you multiply out yields: `1x^2 + 2x^3 + 3x^4 + 4x^5 + 5x^6 + 6x^7 + 5x^8 + 4x^9 + 3x^10 + 2x^11 + 1x^12`. This should look familar to anyone that knows the distribution of the sum of 2 dice rolls

To easily calculate the coefficients of the polynomial, you can pull the coefficients out into an array. `d_1 = [0,1,1,1,1,1,1]`. Note the 0 padding for a face of value '0'. This make the index of the array equal to the value of the face/sum and makes the calculations simpler when implementing it in code. One operation to know is the convolution, denoted `**`. For a for explanation of convoluations there are 2 good 3blue1brown videos on Youtube which explain it, one discusses the discrete case as used here, But what is a convolution?, and others which fully discuss convolutions including the continuous case, which while not necessarily needed here is provided for completeness, 1) Convolutions | Why X+Y in probability is a beautiful mess 2) A pretty reason why Gaussian + Gaussian = Gaussian. when used here we can calculate the frequencies of the sums of dice rolls such that `d_2 = d_1 ** d_1` which will give the the frequencies of the sum of two dice rolls, or the coefficients of the multiplication of the polynomials, you can then repeat the process to get the sum of further dice rolls, `d_3 = d_2 ** d_1`, or more generally `d_n = d_(n-1) ** d_1`. Computing `d_2` yields `[0,0,1,2,3,4,5,6,5,4,3,2,1]`, which again shows the distribution of the sum of 2 dice rolls, note again the 0 padding which indicates there is 0 chance of having a sum of 0 or 1 for 2 dice rolls.

Using the distribution of the sum of dice rolls we can create a survival function for each die, or a probability function that the sum of the die rolls is less than the threshold and the horse has not finished yet. This would be calculated `L(x) = (sum_(i =0)^(T-1) (d_x)_i)/(sum (d_x))`

This would yield an graph that generally looks like this, showing there is 100% chance they haven't won through the first couple throws, then declines and slowly tapers as it becomes more unlikely they haven't not completed and eventually dropping to 0 after the maximum number of rolls it would take to reach the threshold.

With this function we can then calculate the probability of each horsing winning the race. We do this by looping through each turn of the race and calculating the probability each horse wins on that turn `(P_(d_m))(x) = L_(d_m)(x-1) - L_(d_m)(x)`. The probability they haven't won yet on the previous turn minus the probability they haven't won yet on the current turn. That change is the probability they win on any specific turn.

To then calculate each horses probability of winning the race against the other horse we will loop through each turn and loop through each combination of horses winning/not having won yet on that turn calculating the outcome of that scenario, and appropriately adding the chance of winning to each horse, remembering to give the partial win for ties.

`P(d_m) = sum_(t=1)^T(sum_(c={0,1}^p)(c_m frac{prod_(h=1)^P {(L_h(t-1) - L_h(t) if c_h = 1),(L_h(t) if c_h = 0):}}{sum_(h=1)^P c_h}))`

When implementing in code I used a trick to loop through each combination of horses winning. I looped from 1 to `2^p` and took that number in binary. Each bit represented a horse and signaled whether that horse won that turn or had not won yet. This ensured I covered all combinations or horses tying and solo wins, when it was some number with 1 bit equaling '1' (i.e. the powers of 2)

The following formula while it should yield the same result as the above is closer to how the calculation was implemented in code. The one above simply uses more concise mathematical notation.

`P(d_m) = sum_(t=1)^T(sum_(c=0)^(2^P-1)(floor(c/2^m)mod 2 frac{prod_(h=1)^P {(L_h(t-1) - L_h(t) if floor(c/2^m)mod 2 = 1),(L_h(t) if floor(c/2^m)mod 2 = 0):}}{wt(c)}))`

Code

The code used to calculate the probabilities is below. But note some differences. The formulas above show the probablity for any individual die, while the code calculates all players' probabilities at the same time. The code appears to be accurate and the calculated probabilities match simulated race probabilities. If you notice any discrepancies between the formula and the code, defer to the code for this reason.

for (let rolls = 1; rolls < target; rolls++) {
	for (let combo = 1; combo < (2 ** horses.length); combo++) {
		comboOdds = 1;
		comboBits = 0
		for (let horse = 0; horse < horses.length; horse++) {
			let bit = combo >>> horse & 1;
			comboBits += bit;
			comboOdds *= horses[horse].getData(rolls,bit);
		}

		comboOdds = comboOdds / comboBits

		for (let horse = 0; horse < horses.length; horse++) {
			if(combo >>> horse & 1) {
				horses[horse].raceProbWin += comboOdds
			}
		}
	}
}
